# Onboarding Compliance Upload Dashboard

This is a local, dependency-free dashboard for onboarding compliance CSV uploads.

Open `index.html` in a browser, upload an onboarding compliance CSV, then use the summary cards, filters, action queue, breakdowns, and candidate detail drawer.

Run the validation check with:

```powershell
node onboarding-dashboard.test.mjs "C:/Users/sheld/Downloads/Onboarding-Compliance-Report_20260514_1120AM.csv"
```
